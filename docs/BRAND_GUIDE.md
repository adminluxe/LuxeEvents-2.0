# Purple Events — Signature orchidée V1

Mise à jour : 7 septembre 2026.

## Emblème

L’emblème actif est une orchidée pourpre frontale à cinq pétales, centrée sur un cœur champagne. Sa silhouette reste reconnaissable à petite taille et remplace le précédent pictogramme floral abstrait.

## Usage

| Support | Fichier | Usage |
|---|---|---|
| Header, footer et page de confidentialité | `public-purple/images/purple-orchid-emblem-v1.webp` | Fond sombre, affichage 38–48 px |
| Favicon | `favicon-32.png`, `favicon-64.png` | Onglets navigateur |
| Appareil Apple | `apple-touch-icon.png` | Icône 180 px |
| Manifest | `purple-events-icon-192.png`, `purple-events-icon-512.png` | Installation web, usages `any` et `maskable` |

## Palette

- Noir minéral : `#09070b`
- Violet orchidée : `#9d4edd`
- Violet lumineux : `#c277ff`
- Champagne : `#dfc7a1`

## Signature institutionnelle

- Anglais : **A Purple Orchid Group initiative**

## Garde-fou

L’emblème a été créé spécialement pour ce jalon et n’utilise aucun logo tiers fourni. Une recherche d’antériorité de marque reste recommandée avant tout dépôt ou usage institutionnel irréversible.
